# Student Performance Analyzer 📊

A Python-based student performance analysis application that reads
student data from a CSV file and provides useful academic statistics.

## 🚀 Features

- View all students
- Search for a student
- Calculate total marks
- Calculate average marks
- Calculate percentage
- Determine Pass/Fail
- Calculate subject-wise averages
- Find the class topper
- Display pass/fail statistics
- Student ranking

## 🛠️ Technologies Used

- Python
- Pandas
- CSV

## ⚙️ Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Go into the project folder:

cd student-performance-analyzer

Install dependencies:

pip install -r requirements.txt

Run the application:

python main.py

## 📊 Example

The application provides a menu:

1. Show All Students
2. Search Student
3. Show Student Result
4. Subject-wise Average
5. Show Topper
6. Pass/Fail Statistics
7. Subject Performance
8. Class Statistics
9. Student Ranking
10. Exit
